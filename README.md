# 📚 StudyOS

StudyOS is a simple personal study dashboard built using **HTML, CSS, and JavaScript**. It helps students organize their daily tasks, track study progress, and stay productive.

## ✨ Features

- 📋 Task Manager
- 📅 Daily Study Planner
- 📚 Subject Progress Tracker
- ⏳ Pomodoro Timer
- 📝 Notes
- 📊 Study Statistics
- 🌙 Dark Mode
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## 📁 Project Structure

```text
StudyOS/
│
├── index.html
├── css/
├── js/
├── assets/
└── README.md
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Pronob155/StudyOS.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
